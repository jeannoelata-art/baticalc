# baticalc
BatiCalc est une application gratuite qui calcule en quelques secondes les matériaux de vos travaux : parpaings, ciment, sable et gravier pour murs, enduits, bétons, dalles et poteaux. Entrez vos mesures et vos prix : obtenez votre devis estimatif. Pensée pour maçons, entrepreneurs et particuliers, utilisable sur téléphone, sans installation.
